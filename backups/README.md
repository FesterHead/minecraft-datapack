# Mod Backups

This directory stores backup copies of original, unmodified external mods.

## Purpose

For compatibility reasons, it is sometimes necessary to edit external mod files (such as removing specific files/assets from a mod's `.jar` to let our datapack or resource pack take precedence without conflict). 

When a mod is modified:
1. Place a backup of the original, unmodified `.jar` file in this directory.
2. Document the changes made to the modified mod file.

To prevent binary bloat in the git repository, all `.jar` files in this directory are ignored by Git.
