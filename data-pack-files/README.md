# Datapack Source Files

This directory contains the raw source files for the Minecraft datapack.

## Structure

When packaged or loaded into Minecraft, the contents of this folder reside at the root level of the datapack:

- `data/`: The namespace directory containing all datapack functions, recipes, loot tables, advancements, tags, and world generation configurations.
- `pack.mcmeta`: The metadata file required by Minecraft to identify and describe the datapack.
- `pack.png`: The icon image that represents the datapack in the game menu.
- `README.md`: The README file for the datapack.
